개인 리포트 조회

API Endpoint/api/v1/reports/{slug}
HTTP methodGET
메모박제된 결과 조회(재계산 없음). 분석 중이면 pending
파트Report

설명

워커가 완성한 리포트를 보여준다. 결과가 박제(payload로 고정) 되어 있어서 몇 번을 열든 재계산 없이 같은 화면이 나온다. 매장을 떠난 뒤 집에서도 slug로 다시 볼 수 있다.

분석이 아직 안 끝났으면 status: pending을 준다. 클라이언트는 잠시 뒤 다시 요청한다(폴링).

Request

Path 파라미터 slug — /finish에서 받은 값. 추측하기 어려운 문자열로 발급한다.

Response 200

필드타입설명
statusstringpending 또는 ready
characterobject16유형 캐릭터 (type_code, name, one_liner)
top_keywordsarray핵심 취향 키워드
interestedarray관심 보인 상품·전시존 + 그렇게 판단한 근거
recommendationsarray추천 상품 + 추천 이유 + 점수
confidencenumber0~1. 낮으면 "탐색 중"으로 표시
visit_summaryobject이번 관람 요약 (본 전시존/상품 수, 질문 수)

화면 구성 (기획 기준)

핵심 취향 키워드 → 가장 적합한 상품 1개를 크게 노출 + 추천 사유 → 추천순 상위 N개 그리드(관심 있게 본 상품 + 새로 추천된 상품 함께) → 각 상품에 '자세히 보기' / '구매하기(본사 사이트 이동)'

에러 / 관련 테이블

404 NOT_FOUND(잘못된 slug) → reports, taste_profiles
