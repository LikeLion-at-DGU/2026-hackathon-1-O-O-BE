# F. 엔드포인트

## F1. `POST /api/v1/enter` — 입장 + 이어하기 ⬜ (8/13) 🔥최우선

**의존**: D3 · **막고 있는 것**: 프론트 전체 화면

### 서비스 로직 (`visits/services.py`)
- [ ] `resolve_or_issue(uuid)` — 없으면 Visitor 발급, 있으면 조회
- [ ] `find_resumable(visitor)` — `ended_at IS NULL` AND `last_seen_at >= now - RESUME_WINDOW`
- [ ] `expire(visit)` — 30분 초과 미종료 Visit에 `ended_at` 기록 (**리포트 생성하지 않음**)
- [ ] `start(visitor, store)` — Visit + token 생성
- [ ] `summarize(visit)` — 이어하기 모달용 `products_viewed` · `message_count`
- [ ] `store_enter` · `visit_start` 이벤트를 서버가 생성

### 분기 4가지
- [ ] UUID 없음 → Visitor 발급 + 새 Visit, 응답에 `anonymous_uuid` 포함
- [ ] 진행 중 Visit 있음 → **같은 Visit·같은 token 반환**, `resumed: true`
- [ ] 미종료 + 30분 초과 → 만료 처리 후 새 Visit, `resumed: false`
- [ ] `force_new: true` → 진행 중 Visit 만료 처리 후 새 Visit

### 요청/응답
- [ ] 요청: `age_band`(선택) · `gender`(선택) · `force_new`(선택, 기본 false) · 헤더 `X-Anonymous-UUID`(선택)
- [ ] 건너뛰기 허용 — 둘 다 없어도 정상 입장
- [ ] 이어할 때 `age_band`/`gender` **덮어쓰지 않음**
- [ ] 응답: `anonymous_uuid`(신규만) · `visit_id` · `visit_token` · `store{store_id,name}` · `scenes[{scene_id,no,name,products[{product_id,no,name,thumbnail,price}]}]` · `resumed` · `resumed_visit{started_at,products_viewed,message_count}`
- [ ] 인증 없이 호출 가능 (`AllowAny`) — 유일한 공개 사용자 API
- [ ] N+1 제거: `prefetch_related("products")`

### 검증
- [ ] 신규 입장 200 + `resumed: false` + UUID 발급
- [ ] 같은 UUID 재호출 → `resumed: true` + **동일 visit_id·동일 token**
- [ ] `force_new: true` → 새 visit_id
- [ ] `last_seen_at`을 31분 전으로 조작 → `resumed: false` + 이전 Visit `ended_at` 기록
- [ ] `age_band` 잘못된 값 → 400 `VALIDATION_ERROR`
