# 배포 보충 — 가비아 콘솔 절차 & 세션 가이드 대조

**실제 배포 절차는 [`deploy/README.md`](../deploy/README.md)가 기준이다.** 이 문서는 두 가지만 담는다.

1. 가비아 관리콘솔에서 서버를 만들고 지우는 절차 (매뉴얼 요약)
2. 멋사 세션 배포 가이드(AWS EC2+ECR / Docker Hub 기준)를 **그대로 따르면 안 되는 지점**

---

## 1. 서버 생성 시 고를 값

| 항목 | 값 | 이유 |
| --- | --- | --- |
| OS | **Ubuntu 22.04** | `deploy/README.md`가 apt 기준이다 |
| 서버 타입 | High CPU 2vCore / 4GB / 트래픽 1TB | **제공 사양 초과 시 과금** |
| 스토리지 | 루트 100GB 단일 | 50+50으로 나누면 데이터 볼륨을 직접 마운트해야 한다 |
| 로그인 방식 | **비밀번호 방식** | 브라우저 터미널은 **SSH 키페어로 접속이 안 된다** |
| 공인 IP | 1개 | 팀당 지원 범위 |

생성 순서는 VPC → 서브넷 → 공인 IP → 서버. root 비밀번호는 "[가비아 클라우드] 서버가 생성되었습니다" 메일에 있다.

> 터미널 창을 닫아도 세션은 살아 있다. 끝나면 반드시 `exit`.
> `Ctrl+Alt+Del`은 로그아웃이 아니라 **재부팅**이다.

## 2. 보안그룹 인바운드

| 포트 | 소스 | 용도 |
| --- | --- | --- |
| 443 | 0.0.0.0/0 | HTTPS |
| 80 | 0.0.0.0/0 | 인증서 발급 + 리다이렉트 |
| 22 | 내 IP만 (또는 닫기) | 브라우저 터미널이 있어 없어도 된다 |

**8000번은 열지 않는다.** nginx가 앞에서 받고 uvicorn은 `127.0.0.1:8000`에만 바인딩한다(`deploy/oando.service`). 8000을 열면 HTTPS를 우회하는 평문 경로가 하나 생긴다.

## 5. 세션 가이드를 그대로 따르면 안 되는 지점

세션 자료는 일반 Django 기준이라 우리 코드와 어긋나는 곳이 있다. **이미 `deploy/`가 아래를 전부 반영해 두었다.**

| 세션 가이드 | 우리 코드에서는 | 왜 |
| --- | --- | --- |
| `CMD gunicorn project.wsgi` | **uvicorn `config.asgi`** | 챗봇이 SSE 스트리밍이다. WSGI는 청크를 버퍼링해서 응답이 한 번에 나간다 |
| `-e SECRET_KEY=...` | `DJANGO_SECRET_KEY` (둘 다 받게 고침) | 이름이 다르면 값을 넘겨도 조용히 개발용 기본키로 뜬다 |
| `USE_TZ = False` · `TIME_ZONE = Asia/Seoul` | **UTC 유지** | 명세가 `client_timestamp`·`server_received_at`을 ISO 8601 / UTC로 정의했다. 바꾸면 기존 이벤트 시각이 전부 어긋난다 |
| `ALLOWED_HOSTS = ['*']` 하드코딩 | `.env`의 `ALLOWED_HOSTS` | 코드는 한 벌만 두고 환경변수로 가른다 |
| 8000번 포트 직접 노출 | nginx 뒤 `127.0.0.1:8000` | 프론트가 HTTPS라 평문 API는 **mixed content로 차단**된다 |
| `--workers 2` 이상 | **워커 1개** | SQLite는 쓰기가 DB 전체를 잠그고, 화보 폴링 상태가 LocMem이라 프로세스마다 캐시가 따로 논다(= 폴링 404) |
| `psycopg2-binary` | `psycopg[binary]` (3.x) | 이미 requirements에 있다 |
| sqlite를 컨테이너 안에 | 파일을 볼륨/호스트에 | 재배포마다 데이터가 날아간다 |

### Docker Hub 방식으로 갈 경우 추가로 필요한 것

`deploy/`는 systemd + venv 방식이다. 굳이 Docker Hub로 간다면 루트의 `Dockerfile`을 쓰되:

- `.env`를 이미지에 넣지 말고 `--env-file .env`로 넘긴다 (키 개수가 많아 `-e` 나열은 실수가 난다)
- sqlite·미디어를 볼륨으로 뺀다: `-v /srv/oando/data:/app/data -v /srv/oando/media:/app/media`
- HTTPS는 그대로 nginx + certbot이 필요하다. 컨테이너만으로는 해결되지 않는다
- M시리즈 맥에서 빌드하면 `--platform linux/amd64`를 붙인다 (안 붙이면 서버에서 `exec format error`)

**두 방식을 동시에 쓰지 않는다.** 지금 레포에는 `deploy/`(systemd)와 루트의 `Dockerfile`·`docker-compose.prod.yml`·`Caddyfile`(도커)이 함께 있다. 하나를 골라 나머지는 지우는 편이 다음 사람에게 낫다.
